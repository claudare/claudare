# Notes

Notes is a Flutter prototype for the Claudare project. Server configuration is
optional.

## Installation

Only experimental nightly builds are available from [Notes releases][releases].

For access to all available Claudare Flatpak applications, add the
[Claudare Flatpak repository][flatpak-repository] to your software manager.

- Linux: install Flatpak, then open the [Flatpak installer][flatpak-install].
- Android: install Obtainium, then [import Notes][obtainium-import] and check
  for updates to install the app.

Updates follow your software manager or Obtainium settings.

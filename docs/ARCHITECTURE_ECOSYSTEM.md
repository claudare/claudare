# Claudare infrastructur design (needs rewording)

## Key features of the Claudare ecosystem:

- No infrastructure needed. No central server required.
- A suite of applications to do anything an individual needs to do (notes,
  music, contacts, photos, calendar, maps)
- All apps work the same way, as data is replicated via a unified protocol.
- Every device works offline and can do everything. Support for major mobile and
  desktop operating systems.
- Resistant to connectivity losses. Utilization of local connecivity is
  preferred, islanded operation, and graph? replication.
- End-to-end encryption and data ownership. Federated (friend backup) system.
- AGPL licensed code without paywalls.
